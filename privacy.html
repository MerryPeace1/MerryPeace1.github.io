Privacy Policy

Last updated: October 30, 2026

"MerryPeace Overlays" is a personal tool used only by the owner of the MerryPeaceTV YouTube channel to run its own live streams.

What it accesses

With the channel owner's permission (Google sign-in), it uses the YouTube Data API to find the channel's current live broadcast and set that broadcast's thumbnail image. It does not read, collect, store or share data about anyone else.

What is stored

A Google sign-in token is stored only on the channel owner's own computer so thumbnails can be set automatically. Nothing is sent to any other server, and no data is sold or shared.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
